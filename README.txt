JOOTAY LELO — DYNAMIC BUSINESS WEBSITE PROJECT

A polished fictional sneaker brand website made for an HTML/CSS/JavaScript course project.

PAGES
1. index.html — branded landing page, featured products, editorial section, color collection and newsletter
2. shop.html — product catalog, filters, wishlist, add-to-bag and persistent localStorage cart
3. about.html — brand story, manifesto and animated statistics
4. contact.html — inquiry form with JS validation, FAQ accordion and Google Maps

TECHNICAL REQUIREMENTS
HTML:
- Semantic structure
- Headings, paragraphs, links, lists/sections
- Images
- Forms
- Embedded Google Maps

CSS:
- Custom brand identity
- Responsive desktop/tablet/mobile layouts
- Grid and flexbox
- Hover states, badges, buttons, cards and typography
- CSS animations

JAVASCRIPT:
- DOM manipulation
- Click/mouse events
- Keyboard events (Escape and Enter)
- Mobile navigation
- Search overlay
- Product filters
- Wishlist interaction
- Add-to-cart
- localStorage
- Dynamic cart counter
- Form validation
- FAQ accordion
- Animated counters
- Toast notifications

RUNNING THE WEBSITE
Open index.html directly or use VS Code Live Server.

IMPORTANT FOR GITHUB PAGES
Upload all files while preserving the folder structure:
index.html
shop.html
about.html
contact.html
css/style.css
js/script.js

Then enable GitHub Pages from the repository's Settings → Pages and select the main branch/root folder. GitHub will give you a public website URL that can be shared with your sir.
